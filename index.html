05 The build

Wait — what is this?

HALCYON isn't a real product. It's a fictional brand I invented as a canvas — and everything you just scrolled through is the point. I built this to show one thing: that I can design and ship polished, animation-heavy, interactive UI, using AI tools as a force multiplier and hand-tuning every frame. No framework, no page builder, no build step — just vanilla HTML, CSS and JavaScript you can open straight from disk.

Built with

  • Vanilla JS
  • WebGL + GLSL
  • Three.js
  • Motion
  • Canvas 2D
  • CSS design system
  • Zero build step

Designed & built by Purvang Suvagiya

What it demonstrates

  • A hand-written GLSL domain-warp aurora shader driving the hero.
  • An interactive Three.js core — cursor-reactive, scroll-coupled, iridescent.
  • Scroll choreography: reveals, pinned horizontal storytelling, count-ups, an infinite velocity-reactive marquee.
  • Plain native scrolling — no scroll-jacking; every effect samples the real scroll position.
  • Kinetic variable typography that tracks scroll speed.
  • Accessible by default — honors reduced-motion, keyboard focus, and a full no-JS fallback.
  • Ships as static files: nothing to build, nothing to break.
